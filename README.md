# Modals for Giving Advice

An interactive English presentation by Vicente Arredondo and Benjamín Contreras, with the phone game Advice Hotline.

- `index.html`: the presentation. Open it on the screen and press Start.
- `play.html`: the phone page. Players reach it with the QR code in the game.

Next, Back, Space and the arrow keys move through the slides. M mutes the sound. The game can also run without phones.

The QR code uses [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) by Kazuhiko Arase, under the MIT License.

Pepe's voice is synthesised with [Piper](https://github.com/rhasspy/piper) and the Ryan voice, built from the [RyanSpeech](https://www.kaggle.com/datasets/roholazandie/ryanspeech) dataset under CC BY-NC-SA 4.0. It is used here for a non-commercial school project.
